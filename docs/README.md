# 🌐 GitHub Pages – Filmotic Landing Page

Esta carpeta contiene la **Landing Page estática** de Filmotic para descarga directa del APK e información de la app.

## 🚀 Pasos para Activar GitHub Pages en el Repositorio

1. Entra a tu repositorio en GitHub:  
   `https://github.com/Pokaysplash/filmotic-app`
2. Ve a la pestaña **Settings** (Configuración) en la barra superior.
3. En el menú lateral izquierdo, haz clic en **Pages** (dentro de la sección *Code and automation*).
4. En **Build and deployment** > **Source**, selecciona:  
   **Deploy from a branch**
5. En la sección **Branch**:
   - Selecciona la rama: **`main`**
   - Selecciona la carpeta: **`/docs`**
6. Haz clic en **Save** (Guardar).
7. Espera aproximadamente 1 a 2 minutos mientras GitHub Actions procesa el despliegue.
8. La URL pública de tu landing page será:  
   👉 **`https://pokaysplash.github.io/filmotic-app/`**
